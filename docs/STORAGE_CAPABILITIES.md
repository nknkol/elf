## 探测含义

在目标目录内创建随机独占子目录，以排他创建测试 `CaseProbe`/`caseprobe` 是否能
同时保存不同内容；不使用 `lower()` 推测语义。这个测试只覆盖 ASCII，不覆盖
Unicode case folding、正规化或文件名展示规则。

硬链接测试实际调用 `os.link`，若成功，再验证共享 inode、内容联动和链接计数。
EPERM/EACCES 记录为 denied，ENOSYS/EOPNOTSUPP 为 unsupported；其它错误或无法
创建探针时为 unknown，绝不把权限拒绝解释为大小写不敏感。失败不自动复制或建符号链接。

清理仅针对探针创建的私有子目录。失败时 JSON 报告剩余路径且退出非零，不掩盖残留。
不在导入、计划编译或运行普通 guest 时自动探测，也不提交此结果作为授权状态。

## 对产品的影响

- agent 的绑定沿用宿主实际语义，但权限判断必须另行处理大小写别名与挂载边界。
  现有路径字符串策略模型不是权限执行，不能将此探测结果直接当成放行条件。
- Linux rootfs 优先选择大小写敏感的持久 backing；/tmp 仅适合临时使用。已在不敏感
  存储上因同名变体覆盖的数据，不能靠运行时路径翻译恢复。
- 运行时 linkat 保留宿主拒绝，跨虚拟挂载返回 EXDEV；Ubuntu 测试镜像解包的独立
  副本是显式兼容措施，不代表硬链接实现。本轮没有改变这些行为。
- 尚未实现计划自动附加探测、大小写别名的权限拒绝检查、完整只读/default-deny、
  文件名/硬链接虚拟化。下一阶段的只读边界测试需要以混合 backing 为输入，不能仅
  在单一文件系统上验证正向路径再宣称安全。
